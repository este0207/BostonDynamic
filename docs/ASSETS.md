# Provenance des modèles

Les informations ci-dessous proviennent des métadonnées embarquées dans les GLB fournis. Elles ne constituent pas une preuve d’affiliation officielle.

| Modèle | Auteur déclaré | Source |
|---|---|---|
| Spot (Boston Dynamic) High Poly | Julliani | https://sketchfab.com/3d-models/spotboston-dynamic-high-poly-058b16a8c88047e18b1f081e0d15f883 |
| Atlas Robot #scan | Idmenthal | https://sketchfab.com/3d-models/atlas-robot-scan-5ebf41a891e849469fe6b2503b2255f3 |
| drone robot | noortjeschuur | https://sketchfab.com/3d-models/drone-robot-177e6cce2ef44a679238552a5bf6c956 |

Licence déclarée pour les trois modèles : CC BY 4.0, https://creativecommons.org/licenses/by/4.0/.

Modifications de présentation : normalisation de l’échelle, cadrage, éclairage, déplacement et rotation. Atlas reçoit un matériau acier original pour cette mise en scène. Les versions `.web.glb` sont dédupliquées, quantifiées et compressées avec Meshopt ; leur nombre de triangles et leurs textures sont conservés. Les originaux ne sont pas remplacés.

Le parcours est artistique. Spot et Atlas ne sont pas présentés comme une lignée évolutive scientifique. Aucun modèle PETMAN n’est disponible dans le dossier.
